# Tuomas Alahäivälä – verkkosivu-CV

Valmis staattinen CV: HTML + CSS, ilman JavaScriptiä tai ulkoisia kirjastoja.

## Esikatselu
Avaa index.html selaimessa. Pidä style.css samassa kansiossa.

## GitHub Pages
1. Luo repository nimeltä TuomasAlahaivala.github.io.
2. Lisää index.html ja style.css repositoryn juureen (ei cv-alikansioon).
3. Avaa Settings → Pages. Valitse Deploy from a branch, main ja / (root).
4. Kun julkaisu valmistuu, sivu on osoitteessa https://tuomasalahaivala.github.io/.

## Muokkaaminen
- Sisältö: index.html.
- Ulkoasu, värit ja mobiilinäkymä: style.css.
- Värit on määritelty CSS-tiedoston alun :root-osiossa.
- Sivu toimii ilman asennusta, verkkoyhteyttä tai rakennustyökaluja.
- Tulostustyyli on mukana: voit tallentaa selaimen tulostustoiminnolla PDF:n.

Sisältö perustuu toimitettuun CV:hen. Toistuva Highlights-osio on yhdistetty
esittelyyn. Uusia työkokemus- tai osaamisväitteitä ei ole lisätty.
Alkuperäisessä CV:ssä ei ollut sähköpostia tai puhelinnumeroa. Lisää haluamasi
yhteystiedot ennen julkaisua, jotta työnantaja voi ottaa sinuun yhteyttä.
